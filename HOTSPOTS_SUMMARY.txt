================================================================================
IDENTIFIED HOTSPOTS (Ranked by Impact)
================================================================================

🔥 HOTSPOT #1: Lazy Initialization in first next()
   Location: src/iterate.rs:46-104
   Cost: 704ns per iterator
   Impact: Critical for small iterations (10-50 items)
   Breakdown:
     - leaf_for_key() tree traversal:  ~400-500ns (57%)
     - carve_leaf() pointer math:      ~50-100ns  (11%)
     - binary_search() in leaf:        ~50-100ns  (11%)
     - Positioning logic:              ~50-100ns  (11%)

   Optimization opportunities:
     ⭐ Cache iterator positions (3-5x speedup for cursors)
     ⭐ Hint-based positioning
     • Prefetch during traversal
     • Reduce carve_leaf calls

🔥 HOTSPOT #2: Tree Traversal in leaf_for_key()
   Location: src/common.rs:140-158
   Cost: 400-500ns per call
   Impact: 57% of initialization cost
   Factors:
     - Tree height (3-4 levels): ~100-150ns per level
     - Cache misses from pointer chasing
     - Binary search at each branch

   Optimization opportunities:
     ⭐ Iterator position caching
     • Prefetch next tree level
     • Branch prediction hints

🟡 HOTSPOT #3: Binary Search in Leaf
   Location: src/iterate.rs:65-88
   Cost: 50-100ns per initialization
   Impact: 7-14% of initialization cost
   Factors:
     - 7 comparisons for 128-item array (log2(128))
     - Branch mispredictions

   Optimization opportunities:
     • Linear search for small leaves (<32 items)
     • SIMD search for primitive types
     • Branchless binary search

🟡 HOTSPOT #4: Bound Checking in next()
   Location: src/iterate.rs:110-122
   Cost: 2-5ns per item (only for bounded ranges)
   Impact: Shows in bounded range queries (9.23ns vs 2.86ns baseline)

   Optimization opportunities:
     ⭐ Specialized unbounded iterator (20-50% faster)
     • Hoist bound check to per-leaf
     • Branch prediction hints

🟢 HOTSPOT #5: carve_leaf() Calls
   Location: src/layout.rs:318-334
   Cost: 30-50ns per call
   Impact: Called during init + each leaf boundary crossing

   Optimization opportunities:
     • Cache leaf parts in iterator state
     • Already has #[inline] attribute
     ✓ Already quite efficient

🟢 HOTSPOT #6: Leaf Boundary Crossing
   Location: src/iterate.rs:124-136
   Cost: 1.31ns extra per crossing
   Impact: Minimal (already very efficient)

   Optimization opportunities:
     ⭐ Eliminate tail recursion (use loop instead)
     • Prefetch next leaf
     ✓ Already quite optimal
